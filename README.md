# interncircle-web-development
Web Development internship projects completed as part of the InternCircle virtual internship program.
## Task 3 - Interactive To-Do List

A simple interactive To-Do List built using HTML, CSS and JavaScript.

### Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Add tasks using Enter key
- Store tasks using LocalStorage

### Technologies Used

- HTML
- CSS
- JavaScript
- LocalStorage
